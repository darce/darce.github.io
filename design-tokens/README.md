# Portfolio design tokens

`portfolio.tokens.json` is the source for shared spacing, breakpoints, rail sizing, and article typography. It follows the [Design Tokens Format Module 2025.10](https://www.designtokens.org/tr/2025.10/format/): typed tokens, inherited group types, and curly-brace aliases.

Run `npm run tokens` after editing it. Development, checks, tests, and builds also generate `styles/generated/_portfolio-tokens.scss`. Commit the JSON and generated Sass together. Existing Sass names in `spacing.scss`, `typography.scss`, and `breakpoints.module.scss` remain the public API; browser checks consume the same typed JSON.

DTCG dimensions allow `px` and `rem`. Viewport shares, figure shares, character counts, and unitless leading are numeric tokens. Web styles convert the rail share with `* 100vw`, the figure share with `* 100%`, and the monospaced reading measure with `* 1ch`. CSS functions and responsive conditions stay in the consuming styles rather than being encoded as invalid dimension values.

The exporter validates the dimension and number types used by this file, inherited types, alias targets, alias type agreement, cycles, and Sass name collisions. It is a portfolio-specific exporter, not an implementation of every DTCG token type. Palette and motion tokens retain their existing Sass sources.

The article occupies the full available content canvas. The reading-measure token limits summary paragraphs and text-only or stacked article presentations; it does not constrain the article, media, tables, or diagrams. In desktop articles containing inset figures, paragraph boxes span the canvas so individual lines can flow around either side and continue below images. This contextual exception allows continuous prose; a separate paragraph cap would obstruct left-side wrapping.

The shared article renderer supports `<Figure src="image.png" alt="…" caption="…" />` followed by ordinary narrative paragraphs. Inset figures occupy half the full article canvas and alternate right/left with the article gallery. Consecutive paragraphs and subsection headings flow around them without image-and-paragraph wrappers. Legacy nested children remain supported as siblings in the same continuous flow. Use `layout="wide"` for evidence whose details require the full canvas, `side="left"` or `side="right"` for a deliberate placement, and `inspectable` for a modal image viewer. Supply intrinsic `width` and `height` for local images absent from the responsive image manifest. Narrow containers stack figures in the same reading order. Responsive image `sizes="auto, 100vw"` uses the rendered image width where supported and a conservative viewport fallback, independent of the prose measure.

The viewer fits and enlarges the image to the available window, including images whose intrinsic size is smaller. `article.viewer` tokens set its edge spacing, padding, minimum control size, and zoom factor. Zoom doubles the fitted image and allows keyboard or pointer scrolling; Fit to window restores it. Native modal dialog behavior makes background content inert and supports Escape; explicit Tab boundary handling cycles focus inside the viewer. Close restores focus to the opening button. The viewer retains the active light/dark theme.
