This reference accompanies the [product story](/projects/visual-search-workbench/) and the [design process](/research/visual-search-workbench-process/). It records the detailed states for version 0.2.3, rather than serving as a step-by-step introduction.

The drawings were checked against the 0.2.3 source. A test in the product repository checks quoted interface strings against their named Swift files. The screenshots in the product story show 0.2.0, before the rename from Semantic Image Search and the thumbnail changes in 0.2.3.

The paths, filenames, and counts below are examples from the documented states. In particular, the missing-model screen shows recovery from an unreadable custom model folder; the downloadable app bundles its models.

## 8. Missing model and settings recovery

**Screen 8 — Missing model and settings recovery.**

Settings explains library access, model recovery, content handling, and the optional local layer-naming service. Ollama naming is off by default; when enabled, it sends small crops to a service on the same Mac.

<AsciiScreen label="Screen 8, recovery: a model-folder panel naming /Volumes/Butter/cache/sis-coreml-export as unreadable with Choose and Reset controls, above Settings listing library folders, the content policy, and the off-by-default local Ollama naming option.">
