## Recovering a Flash archive in 2023

Barbara Beirne's photography archive lived entirely inside a Flash website that had stopped working years ago. The original source files and developer were unavailable. In 2023, I was brought in to recover the images and rebuild the site.

## Recovering the images

The images were embedded in a compiled .SWF binary file. I used [FFDec](https://blog.free-decompiler.com/), an open-source Flash decompiler, to extract usable assets from the binary. It took some work to get clean exports, but the tool pulled the full image set.

![Black and white image of three Cambodian teens standing in front of high school lockers](/images/barbara-beirne-extracted-image.png)*Image extracted from a .SWF file using FFDec*

## Rebuilding with Web Components in 2026

In 2026, I rewrote the live site with Web Components and JavaScript, using Rollup for the build and Sass for styling. The full-screen image carousel and navigation support keyboard interaction. Keeping the presentation in web components gave the archive a browser-based foundation for later maintenance.

Barbara's images carry a lot of weight. We decided that a minimal, stark design would frame her work best.
